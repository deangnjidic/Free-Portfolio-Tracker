📋 What's New

Latest features, improvements, and bug fixes for Free Portfolio Tracker

v2.0.0 August 16, 2026

✨ Three-Way Ownership

  • Joint holdings — every asset can now be assigned to Person 1, Person 2, or Joint, while Total Portfolio remains the calculated household total
  • Shared owner filters — switch between Total Portfolio and individual ownership views across Portfolio, Charts, History, and Compare
  • Complete data support — Joint holdings are included in snapshots, transactions, comparisons, charts, JSON backups, and CSV imports

🎨 Dashboard & Chart Redesign

  • Compact Portfolio dashboard — denser holdings, clearer ownership totals, a segmented allocation overview, and collapsible detail panels
  • Modern chart system — consistent card styling, tooltips, colors, legends, filters, empty states, and improved rendering performance
  • Redesigned History — full-width value chart, compact metrics, owner-aware values, expandable snapshots, allocation details, and holding activity
  • Unified application shell — consistent headers, actions, spacing, owner controls, and responsive behavior across functional pages
  • Cleaner page endings — long instructional articles were replaced with compact About disclosures linking to the Guide and FAQ

🛡️ Data Safety

  • Automatic backup reminders — receive a reminder after seven days without an initial export and whenever the latest backup becomes 30 days old
  • Export tracking and snooze — completed exports reset the reminder, while Remind Me Later postpones it for seven days

🔧 Fixes

  • Removed chart jitter and slow scrolling caused by unnecessary animation and redraw work
  • Fixed Asset Allocation tooltip opacity, stacking, and overlap with the chart center value
  • Removed obsolete hard-coded owner identifiers and standardized neutral Person 1 / Person 2 defaults
  • Improved cache handling so redesigned scripts and styles load reliably after updates
v1.40.0 February 19, 2026

✨ Multi-Provider CSV Import System

  • 9 broker parsers — M1 Finance, Robinhood, Charles Schwab, Fidelity, TD Ameritrade, Trading 212, eToro, Coinbase, Interactive Brokers (IBKR)
  • Auto-detection engine — automatically identifies your broker from CSV format with manual override option
  • File picker with drag-and-drop — upload CSV files directly or paste text
  • Preview table with inline editing — review and edit symbol, name, quantity, and type before importing
  • Row removal — remove unwanted assets from preview before import
  • Manual column mapper — generic fallback for unsupported CSV formats; map your columns to Symbol/Name/Quantity
  • Crypto symbol resolver — converts plain crypto symbols (BTC, ETH) to Finnhub format (BINANCE:BTCUSDT)
  • Person assignment — assign to Person 1, Person 2, or Both (50/50 split)
  • 4-step wizard UI — Load → Review & Edit → Assign Person → Import with progress indicators
  • Provider detection badge — shows detected broker with override dropdown
  • Import summary — displays assets added vs updated after import
  • Fully responsive mobile design — 2x2 grid layout for steps, optimized touch targets
  • Dynamic person names loaded from app settings
